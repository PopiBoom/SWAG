# SWAG_ZOV_NEFOR.exe — раскадровка

**Формат:** 1920×1080, 60 fps, ровно 120 с (7200 кадров), без голоса.
**Единая нить:** чат — это «неизвестная программа», которую система пытается проверить, упорядочить и остановить.
Каждая попытка навести порядок (проверка → админ → ножницы → заклинание → «ОСТАНОВИТЬ ХАОС») делает хаос больше,
пока система не признаёт: хаос — основная функция, и «устанавливает» приложение. Сквозные носители: системные окна
в стиле старой ОС, пузыри Telegram, курсор, счётчик непрочитанных, кислотно-зелёные частицы.

**Музыка:** Kevin MacLeod — «Voxel Revolution» (CC BY 4.0), 123 BPM, такт = 1,951 с.
Интро 0–10,5 с — собственный синтезированный дрон. Сегмент A: трек с 13,67 с (бар 7, вход хай-хэтов) с 10,5 с видео.
Комедийные паузы — заглушения на 1–2 доли. Кульминация — полная тишина 92,45–99,5 (только SFX).
Сегмент B: самый плотный удар трека (бар 40, 78,06 с) возвращается на 99,5 с и закрывается на 117,06 с.
Все SFX синтезированы с нуля (`tools/audio.py`), карта событий — общая с картинкой (`js/data.js → CUES`).

Ниже: варианты (3–5) → выбор (✔) и причина; затем практическая карточка сцены.
Время: `b(x)` = 10,5 + x·1,951 с (доли такта от входа бита).

## 1. Запуск неизвестной программы · 0–10,5
Варианты: (а) терминал → ретро-окно загрузки → красный ERROR → кнопка ✔; (б) BIOS-экран с POST-проверкой;
(в) антивирус сканирует файл в 3D-туннеле; (г) «синий экран» с QR-кодом.
✔ (а): прямо следует брифу и задаёт сквозной язык системных окон для всего ролика.
- Курсор мигает → печать «Обнаружена неизвестная программа…» (клавиатурные щелчки).
- Окно загрузки «SWAG_ZOV_NEFOR.exe», три проверки, полоса замирает на 6,2 → глитч → красный экран 6,6:
  «ERROR 404: АДЕКВАТНОСТЬ НЕ НАЙДЕНА» (дрожание, RGB-сдвиг), критическая ошибка (SFX).
- Три тоста: 62 объекта / 21 в сети / хаос 999 %. Кнопка «ВСЁ РАВНО ЗАЙТИ», курсор подлетает по дуге, hover → нажатие 10,3.
- Камера: медленный наезд с лёгким креном; на ERROR — толчок.
- Выход: кнопка рассыпается в зелёные частицы на 10,5 = первый удар музыки.

## 2. Логотип из портала · 10,5–14,4
Варианты: (а) частицы закручиваются в портал, логотип вылетает из глубины ✔; (б) логотип собирается из пикселей;
(в) логотип печатается 3D-принтером; (г) логотип «устанавливается» как программа.
✔ (а): даёт глубину и мощный вход на бите; (г) сохранено для финала.
- Кольца портала в перспективе, логотип из z=-3000 с перелётом; «.exe» фиолетовым; подпись «Это не чат. Это диагноз интернета.» на b(1).
- Камера облетает ±8°, на 13,6 пролёт вперёд в интерфейс Telegram (выход — наезд в окно чата).
