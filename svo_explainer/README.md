# «СВО: как это работает?» — 75-секундный образовательный эксплейнер

1920×1080 · 30 fps · 75.0 с · H.264 + AAC · русский закадровый голос, музыка и звуковой дизайн.
HTML5 Canvas 2D с собственной 3D-проекцией, один `requestAnimationFrame`, всё состояние вычисляется из времени `t`
(детерминированно: seeded random, без накопления), поэтому плеер, перемотка и покадровый экспорт дают одинаковую картинку.

## Что внутри

| Путь | Что это |
|---|---|
| `index.html` | плеер: открыть через локальный сервер, ▶ или пробел; `?t=40` — старт с 40-й секунды |
| `js/core.js` | математика, шум, 3D-камера, типографика (появление по буквам), topojson, зерно/виньетка, HUD, glitch |
| `js/scenes_a.js` | 1 вступление-карта · 2 командный центр · 3–4 рельеф с линией фронта → логистическая сеть |
| `js/scenes_b.js` | 5 космос, спутники, голопанель · 6 лаборатория с каркасными моделями |
| `js/scenes_c.js` | 7 «Люди» (документальная стилизация) · 8 частицы → экономический граф · 9 система → карта Украины |
| `js/main.js` | таймлайн сцен, переходы, субкадровый motion blur, плеер и режим экспорта |
| `tools/compose.py` | офлайн-синтез музыки и SFX, сведение с голосом, приглушение музыки под речь |
| `tools/render.mjs`, `tools/render_all.sh` | покадровый рендер `i/30` в 4 потока → FFmpeg |
| `tools/verify.mjs` | проверка готового MP4 |
| `audio/vo_*.wav`, `audio/vo_words.json` | реплики голоса и их пословные таймкоды (для синхронизации графики) |
| `STORYBOARD.md` | единая нить, варианты для каждой сцены, тайминг голоса, звук |
| `REVIEW.md` | журнал итераций и проверки готового файла |

## Сборка

```bash
pip install numpy scipy soundfile        # для compose.py
node tools/serve.mjs &                   # http://localhost:8140/
python3 tools/compose.py                 # audio/soundtrack.wav
tools/render_all.sh export/frames        # export/frames/picture.mp4
ffmpeg -i export/frames/picture.mp4 -i audio/soundtrack.wav -map 0:v -map 1:a -c:v copy -c:a aac -b:a 256k \
       -t 75 -movflags +faststart export/svo_kak_eto_rabotaet_1080p30.mp4
node tools/verify.mjs export/svo_kak_eto_rabotaet_1080p30.mp4 export/check.jpg
```

| Ресурс | Источник | Условия |
|---|---|---|
| Границы стран 1:50 млн, суша 1:110 млн | Natural Earth через `world-atlas@2.0.2` (jsdelivr) | общественное достояние |
| Шрифт Montserrat (variable) | Google Fonts | SIL Open Font License |
| Голос | синтез Piper TTS, голос `ru_RU-ruslan-medium` (rhasspy/piper-voices), обучен на корпусе RUSLAN (ruslan-corpus.github.io) | **CC BY-NC-SA 4.0 — только некоммерческое использование**, с указанием авторства; для коммерческой публикации замените голос (реплики — `audio/vo_*.wav`, затем `compose.py`) |
| Музыка и все звуки | синтезированы с нуля в `tools/compose.py` | оригинальная работа, без сэмплов |
| Вся графика, модели, иллюстрации | нарисованы кодом | оригинальная работа |

Карты и схемы условные: без реальных позиций, направлений и цифр; экономический граф помечен «условная визуализация».
Сцена «Люди» — стилизованная иллюстрация, не хроника.
