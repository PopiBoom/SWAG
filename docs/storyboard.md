# SWAG_ZOV_NEFOR.exe — DIGITAL ANARCHY · раскадровка

Формат: 1920×1080, 60 fps, ~117 с (112 с ролик + 5 с титров). Без голоса, только титры.
Музыкальная ось — «Heart of Machine» (xezno, CC-BY 3.0), 90 BPM, дроп трека 58.79 с → 66.00 с ролика
(смещение +7.21). Финальный удар — вход плотной секции трека 122.95 с → 103.00 с ролика (три доли-отсчёта перед ним).
Интро/реанимация — «Dark Ambient Loop 13» (farcodev, CC-BY 3.0).

Единая нить: файл запускается → чат → чат прорастает в сеть → сеть объявляет свои законы →
законы взрывают интерфейс в город → город рушится, но система перезагружается и не умирает.
Каждый переход — причинное действие предыдущей сцены (экран → портал, логотип → зал, осколки → город, сбой → монитор).

| Сцена | Время | Варианты (выбран ★) |
|---|---|---|
| I Неизвестный файл | 0–17.5 | ★ терминал как изогнутая CRT-плоскость в 3D, камера наезжает с наклоном к строке EXECUTING; заголовок собирается из частиц шума · плоский терминал с zoom · загрузочный BIOS-экран · радиопомехи → текст |
| II Создание хаоса | 17.5–35.2 | ★ долли по проходу заброшенной серверной, объёмный луч на единственный живой ПК, чат на мониторе, голограммы-маски поднимаются из экрана · вид сверху на стол · сплит-скрин чатов |
| III Обитатели | 35.2–50 | ★ пролёт сквозь экран в пустоту, 62 узла-маски на зелёной сети вокруг голо-логотипа, облёт, сеть запутывается · строй силуэтов · карта-созвездие |
| IV Законы беззаконья | 50–66 | ★ зал с рядами стоек, массивный терминал, строки по 2 доли такта, красный свет на паузе трека, разбитие экрана на дропе · голосование · конституция-свиток |
| V Цифровая анархия | 66–84.7 | ★ быстрый пролёт по мегаполису из окон-переписок, голо-слова на сильных долях каждого такта, WARNING, распад на пиксели с отъездом к башне · город с дрона статично · карта метро |
| VI Не остановить | 84.7–117 | ★ обрыв в темноту, старый монитор, reboot, две фразы, удар — название на весь экран, статусы, финальный глитч, титры |

Таймкоды ключевых событий — в `src/timeline.js` (общий источник для изображения и звука).
